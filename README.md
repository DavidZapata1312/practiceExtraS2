# Menú de Opciones en Python

Este proyecto contiene un menú interactivo que permite al usuario elegir entre varias opciones matemáticas para realizar ciertas operaciones. Las opciones incluyen verificar si un número es par o impar, verificar si un año es bisiesto, calcular la suma de números hasta un valor dado y mostrar todos los números impares hasta un número dado.

## Funcionalidades

El programa ofrece las siguientes funcionalidades:

1. **Verificar si un número es par o impar:**  
   El usuario ingresa un número, y el programa determina si es par o impar.

2. **Verificar si un año es bisiesto:**  
   El usuario ingresa un año, y el programa indica si ese año es bisiesto o no.

3. **Calcular la suma de los números de 1 hasta un número dado:**  
   El usuario ingresa un número positivo, y el programa calcula la suma de todos los números desde 1 hasta ese número.

4. **Mostrar todos los números impares hasta un número dado:**  
   El usuario ingresa un número, y el programa muestra todos los números impares desde 1 hasta ese número.
